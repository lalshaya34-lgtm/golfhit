# Perfect Orbit Golf

A polished 2D golf trainer inspired by the feel of Perfect Orbit, with upgrades, visuals, audio, leaderboard, and local progress tracking.

## Run locally

Open the project folder in a browser directly, or serve it with a tiny static server:

```bash
cd /path/to/project
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Features

- Drag-to-aim golf shots
- Training drills for power and accuracy
- Unlockable skins
- Shop upgrades for power and accuracy
- Local leaderboard
- Background music and SFX generated in-browser
- Mute toggle
- Parallax / camera follow / polished HUD
- Saves progress with localStorage
